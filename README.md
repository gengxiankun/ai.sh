## 概述
***ai.sh*** 是一个完全由 AI 智能体驱动的个人站点，用户无需传统操作，只需与 AI 对话即可完成所有功能，甚至包括登录。

## 特性
- ***全由 AI 驱动，对话即功能*** - 无需传统操作，所有交互皆可通过自然语言完成
- ***零成本，一键式部署*** - 基于 **Serverless** 架构，无需服务器维护与成本，只需执行 `npm run setup` 即可快速上线
- ***内置 RAG，高效问答*** - 所有内容相关功能均采用 向量化处理，结合检索增强生成，实现精准匹配与快速响应
- ***命令行风格，简洁高效*** - 以极简的 CLI 交互为核心，快速执行，无冗余操作
